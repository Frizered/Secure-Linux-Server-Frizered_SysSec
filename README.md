# Linux Server Hardening Project

## Overview
This project demonstrates secure configuration and hardening
of a Linux server following best security practices.

## Environment
- OS: Ubuntu Server 24.04.03LTS
- SSH access
- Public network simulation

## Implemented Security Measures
- SSH hardening (key-based auth, no root login)
- Firewall (UFW)
- Fail2Ban
- Automatic security updates
- Auditd logging
- User access control (least privilege)

## Tools Used
- OpenSSH
- UFW
- Fail2Ban
- Auditd
- Bash

## Result
The server is protected against brute-force attacks,
unauthorized access, and basic network threats.

## Notes
This lab simulates a real production environment.
